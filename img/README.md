# Tower and hero pictures

Upload one PNG per tower or hero into this folder, named exactly as below.
Square images with a transparent background look best (about 128×128 px or larger).
Any picture that's missing falls back to the built-in icon, so you can add them a few at a time.

To upload on GitHub: open this `img` folder → **Add file → Upload files** → drag the PNGs in → **Commit changes**.
